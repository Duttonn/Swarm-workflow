# Board thread contract (harness -> monitor/webui)

Event: `type = "board_post"`, `name = <agent>`, `phase_id = ""`, traced live during each round
(owner-thread poll every SWARM_BOARD_POLL seconds, default 3) and once more after the round.
Each post file is traced exactly once; `started_at` on the event row is the trace time.
Payload keys: `agent` (file prefix before `--`), `file` (e.g. `windows--note-2.md`), `chars`
(full length), `text` (first 4000 chars), `mentions` (sorted lowercase names parsed with
`@([a-z0-9_-]+)`, may include `"all"`), `thread` (always `"main"`: one group thread per swarm),
`posted_at` (file mtime, ISO 8601 UTC, seconds).

Digest file: `<session>/board/thread.md`, regenerated by the harness on every poll, read-only for
agents. Three header lines, then one line per post, oldest first:
`[HH:MM:SS] @agent (file): first 300 chars, whitespace collapsed`. Harness files (`NNN--*`,
`thread.md`) are never posts. Posts are still one file each; never write into the digest.
Tagging: the first line of a post names the agents it concerns (`@windows @rooftops`, or `@all`).
Mentions are parsed from the whole text, so a mid-text `@name` also counts.

Messages for agent X, from the trace: `board_post` events where `"x" in mentions` or
`"all" in mentions`, plus those whose `agent` is a roster neighbour of X (the two names next to
X in `run_contract.payload.agents`), excluding X's own posts; order by `posted_at`, then `file`.
